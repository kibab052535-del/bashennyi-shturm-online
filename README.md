# Башенный штурм — онлайн 1 на 1 (MVP)

Проект на основе `v18`. Включает страницу игры и Node.js/WebSocket-сервер для комнат по коду.

## Запуск на компьютере

1. Установите Node.js 18 или новее.
2. В папке проекта выполните:

   ```bash
   npm install
   npm start
   ```

3. Откройте `http://localhost:3000`.
4. Игрок 1 нажимает **Создать комнату** и отправляет пятизначный код другу.
5. Игрок 2 открывает тот же адрес, вводит код и нажимает **Войти**.

Для игры между разными устройствами сервер должен быть доступен из интернета по HTTPS/WSS. Бесплатные тарифы хостингов меняются и могут засыпать при простое.

## Размещение бесплатно (насколько позволяет тариф)

Самый простой вариант — развернуть этот репозиторий на Render как **Web Service**:
- Build command: `npm install`
- Start command: `npm start`
- Runtime: Node

Сайт и WebSocket используют один адрес; отдельный `serverUrl` обычно оставляют пустым. На HTTPS-сайте WebSocket автоматически переключается на `wss://`.

## Важные ограничения текущего MVP

- Это ранний прототип синхронизации, а не защищённый соревновательный сервер: состояние боя рассчитывает создатель комнаты, второй игрок получает снимки состояния.
- Хост должен оставаться подключённым до конца матча.
- Не предназначено для публичных турниров или защиты от читов. Для надёжной версии нужны серверная проверка действий, обработка переподключения, контроль частоты сообщений и тесты на двух реальных устройствах.
- Проверьте игру на двух устройствах после развёртывания. В текущей среде автоматический браузерный тест не гарантирован.
